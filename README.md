# Remix of Dialen (ventas en WhatsApp con AI)

Construye la estructura completa de un SaaS B2B que funcione como asistente de ventas con IA para WhatsApp Business.

🎯 OBJETIVO

Empresas conectan su WhatsApp y pueden:

 Ver conversaciones con clientes

 Recibir sugerencias de respuesta para vender mejor

 Estandarizar su proceso comercial

🧱 DEFINIR

Quiero que generes:

1. ESTRUCTURA DEL PRODUCTO

 Módulos principales del SaaS

 Cómo se organiza todo el sistema

 Navegación completa

2. UX/UI COMPLETO

Diseña toda la interfaz:

Sidebar izquierdo:

 Chats

 Clientes

 Base de conocimiento

 Métricas

 Configuración

Vista principal:

 Lista de chats

 Chat activo

 Panel de sugerencias IA

Dentro del chat:

 Mensajes cliente

 Respuesta sugerida

 Botón para usar respuesta

 Indicador de oportunidad de venta

3. FLUJO DEL USUARIO

Explica paso a paso:

 Registro

 Login

 Conexión con WhatsApp

 Uso diario del sistema

 Cómo responde a clientes

4. MVP (MUY IMPORTANTE)

Define:

 Qué se construye primero

 Qué funcionalidades NO incluir aún

 Cómo lanzar lo antes posible

5. ROLES DE USUARIO

 Admin

 Manager

 Vendedor

Con permisos claros para cada uno

🎯 OBJETIVO DEL OUTPUT

Debe quedar claro:

 Cómo se ve el producto

 Cómo se usa

 Qué se construye primero
